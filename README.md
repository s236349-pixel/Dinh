# 🚀 MERN Stack Cloud Deployment Project

Ứng dụng Quản lý Sinh viên xây dựng bằng mô hình MERN Stack (MongoDB, Express, React, Node.js), được container hóa bằng Docker và triển khai lên Cloud PaaS (Render).

## 🛠️ Công nghệ sử dụng
- **Frontend:** React, Vite, Nginx, Docker
- **Backend:** Node.js, Express, Mongoose, Docker
- **Database:** MongoDB Atlas (Cloud Database)
- **Deployment & DevOps:** Render (Cloud PaaS), Docker Hub, Git & GitHub
